# Metrias Medical — Marketing Website

Marketing site for [www.metriasmedical.com](https://www.metriasmedical.com).

## Stack

- **Astro** — Static-first, zero JS by default
- **React** — Interactive islands only (Grainient background, hover-expand panels)
- **Tailwind CSS v4** — Design tokens via `@theme` block
- **TypeScript** — Strict mode

## Development

```bash
npm install
npm run dev        # localhost:4321
npm run build      # static output to ./dist/
npm run preview    # preview production build
```

## Branch Strategy

- `dev` — Active development branch, and the branch that deploys production
- `gh-pages` — Legacy, superseded by the Actions workflow on 2026-04-11
- `main` — Legacy, do not use

Merge to `dev` via PR only. The repo default branch is still `main`, so set the base explicitly (`gh pr create --base dev`) — a PR merged into `main` deploys nothing and fails silently.

## Deployment

`public/CNAME` must contain `www.metriasmedical.com`. Pushing to `dev` triggers `.github/workflows/deploy.yml`, which builds static HTML to `dist/` and publishes it to GitHub Pages — roughly one minute from merge to live.

## Brand Assets

Astro copies `public/` verbatim into `dist/`, so every file there is a permanent public URL.

- **`public/images/brand/`** — logo assets hotlinked as `<img src>` from Metrias email signatures, served from `https://www.metriasmedical.com/images/brand/`.
- **Use the `www` host** — the bare apex 301-redirects, and some mail clients will not follow a redirect for an image.
- **Filenames are versioned** — publish `-v2` rather than overwriting. GitHub Pages hardcodes `Cache-Control: max-age=600` and cannot be configured, and Gmail proxies images through its own cache, so an in-place replacement can serve stale bytes indefinitely.
- **Source** — generated by `build300.py` in the `brand/anim` working set (outside this repo); the mark itself derives from `logo_mark.svg` in the Metrias brand Drive folder.

Already-sent email fetches these exact paths every time it is opened. Never move, rename, or delete them.
